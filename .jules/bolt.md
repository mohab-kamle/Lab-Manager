## 2024-05-31 - Optimization Plan
**Learning:** Found an opportunity to optimize `router.get("/", ...)` endpoints in both `employee.js` and `patient.js` by adding `separate: true` to hasMany includes. In `tests.js` it was noted that "The `/all-with-components` route in `server/routes/tests.js` uses `separate: true` for both `components` and `questions` associations to optimize performance by avoiding Cartesian products." We can apply this optimization to other `findAll` calls that include multiple hasMany relationships. Note that `separate: true` is ONLY supported for `hasMany` relationships in Sequelize, and NOT for `belongsToMany` relationships. Also, an anti-pattern of using `Date.now()` for ETag was removed, as it guarantees a cache miss.
**Action:** Add `separate: true` to the `phones` includes in `server/routes/patient.js`, and the `branch_has_employees` and `phones` includes in `server/routes/employee.js`. Removed the `ETag` using `Date.now()` since it defeats caching.

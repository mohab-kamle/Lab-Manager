# Welcome to LabManager User Guide

LabManager is a comprehensive laboratory management system designed to streamline the operations of medical laboratories. It provides dedicated interfaces and features for different roles within the organization, including administrators, employees, doctors, receptionists, and patients.

## Who is this guide for?
This guide is written for everyone using LabManager:
- **Teaching Assistants & Professors:** To understand the system's workflow and use cases for educational purposes.
- **New Users & Staff:** To quickly learn how to navigate the system and perform daily tasks.
- **Patients:** To understand how to access their medical reports and invoices.

## Key Features

- **Role-Based Access Control:** Distinct dashboards and permissions for Admins, Employees, Receptionists, and Patients.
- **Medical Report Management:** Complete lifecycle management of patient tests, cultures, and antibiotic sensitivities.
- **Billing System:** Integrated invoicing, contract pricing, and package management.
- **Multi-tenant isolation:** Ensures that data (like patients and phone numbers) is securely scoped per laboratory.

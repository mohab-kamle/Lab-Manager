# Doctor and Chemist User Guide

As a **Doctor** or **Chemist**, your primary role in the LabManager system is to manage the scientific and diagnostic aspects of the laboratory.

## Medical Reports Management

### Entering Results
*   **Test Results:** Input values for patient tests. Ensure they fall within the specified reference ranges, and add clinical notes if necessary.
*   **Cultures & Antibiotic Sensitivities:** Input specific culture results and select the effective antibiotics for patient reports.
*   **Approval & Publishing:** Review completed tests and finalize medical reports so they become available to Receptionists and Patients.

## Laboratory Management

*   **Test Catalog Maintenance:** You can view (and sometimes manage, depending on exact permissions) the available list of Tests, Cultures, and Test Groups.
*   **Quality Control:** Ensure that data entry is accurate and corresponds to correct patient records.
*   **Monitoring Pending Reports:** Track which medical reports are still pending and require your attention.

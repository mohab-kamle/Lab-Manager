# Implementation Plan: Universal Code Component (Barcode & QR) - V2

Extract and unify barcode and QR code generation logic into a reusable component and hook, optimized for both Web UI and PDF reports.

## Proposed Changes

### [NEW] Universal Code Utility Files

We will add the new files directly to `client/src/components/pdf/` as requested.

#### [NEW] [useUniversalCode.js](file:///home/zaid/Project/Lab-Manager/client/src/components/pdf/useUniversalCode.js)
A headless hook that handles the generation of Data URLs for both Barcodes and QR Codes. 
- Supports `type: 'barcode' | 'qrcode'`.
- Supports passing `format` as a parameter (defaults to `CODE128` but can be overridden).
- Uses `useMemo` for performance optimization.
- Encapsulates `jsbarcode` and `qrcode` library calls.

#### [NEW] [UniversalCode.jsx](file:///home/zaid/Project/Lab-Manager/client/src/components/pdf/UniversalCode.jsx)
A React component for Browser UI rendering.
- For `barcode`: Renders a `<canvas>` element using `jsbarcode`.
- For `qrcode`: Renders a `<canvas>` using `qrcode`.
- Exposes props for: `type`, `value`, `format`, `width`, `height`, `lineColor`, `background`, `margin`, `displayValue`, and `fontOptions`.
- Implements "Quiet Zones" (minimum margins) by default.
- Allows format to be passed as a prop/parameter.

## Technical Details

### 1. Parameterized Creation
- The hook and component will accept a `format` parameter. 
- If no format is provided, it will use the automated detection logic (defaulting to `CODE128`).

### 2. High Resolution & Quiet Zones
- For the `<canvas>` rendering in the Web UI, we will ensure high-DPI support so that barcodes remain sharp when printed from the browser.
- A minimal quiet zone (margin) will be enforced to ensure scanners can identify the start and end of the code.

### 3. Consistency
- The PDF logic remains unchanged in terms of output (it still receives a Data URL), but the source of that URL is now centralized.

## Verification Plan

### Manual Verification
1. **Web UI Test:** Verify `<canvas>` rendering of barcodes and QR codes with different formats and styles.
2. **PDF Test:** Generate a report and ensure the codes are present and correctly formatted in the PDF.
3. **Scan Test:** Use a mobile scanner to verify the codes generated by both the Web UI (canvas) and the PDF (dataURL).

# Employee User Guide

As an **Employee**, you have basic access to the LabManager system. The Employee role is a general-purpose role that provides access to core system features without the specialized permissions granted to Administrators, Chemists, or Receptionists.

## Core Features

### Dashboard Access
*   **Employee Dashboard:** View your personalized dashboard with an overview of your assigned workspace and relevant system information.
*   **Navigation:** Access the areas of the system that your permissions allow, using the sidebar navigation.

### System Usage
*   **Read-Only Access:** Depending on your specific permissions, you may be able to view patient records, test catalogs, and reports without the ability to modify them.
*   **Supporting Tasks:** Assist other roles by handling routine tasks such as data lookups, record searches, or report retrieval.

## Account Management

*   **Profile:** View and manage your account profile, including name and contact information.
*   **Password:** Change your password at any time. On first login, you will be prompted to set a new password for security.
*   **Session Security:** Your session is secured with authentication tokens and automatic expiry. Always log out when leaving a shared workstation.

# Chemist User Guide

As a **Chemist**, your primary role in the LabManager system is to perform laboratory analysis and enter the scientific data that forms the foundation of every medical report. You handle the hands-on diagnostic work — running tests, recording results, and managing cultures and antibiotic sensitivities.

## Test Results

### Entering Results
*   **Standard Tests:** Input values for patient laboratory tests. Ensure they fall within the specified reference ranges, and flag any out-of-range values for review.
*   **Reference Ranges:** The system displays the normal reference range alongside each test parameter, helping you quickly identify abnormal results.
*   **Batch Entry:** When processing multiple samples, enter results efficiently through the batch entry interface.

### Cultures & Antibiotic Sensitivities
*   **Culture Results:** Record culture growth findings, identify organisms, and document culture-specific observations.
*   **Antibiotic Sensitivity:** Select the tested antibiotics and record sensitivity results (Sensitive, Intermediate, Resistant) for each identified organism.
*   **Multi-organism Support:** Handle reports with multiple organisms, each with their own antibiogram profile.

## Quality Control

*   **Data Accuracy:** Double-check all entered values before submitting. Once results are submitted, they are finalized and ready for the patient.
*   **Test Catalog:** View the available list of Tests, Cultures, and Test Groups configured by the Administrator.

## Workflow

*   **Pending Samples:** Track which samples are awaiting your analysis through your Chemist dashboard.
*   **Completed Reports:** Monitor the history of reports you have finalized.

# Welcome to LabManager User Guide

LabManager is a comprehensive laboratory management system designed to streamline the operations of medical laboratories. It provides dedicated interfaces and features for different roles within the organization, ensuring each team member has access to exactly the tools they need.

## Who is this guide for?

This guide is written for everyone using LabManager:
- **New Users & Staff:** To quickly learn how to navigate the system and perform daily tasks.
- **Administrators:** To understand system configuration, user management, and oversight capabilities.
- **Patients:** To understand how to access their medical reports and invoices.

## System Roles

LabManager supports **five distinct roles**, each with its own dashboard and permissions:

| Role | Description |
|---|---|
| **Administrator** | Full system access — manage users, branches, tests, pricing, and system configuration. |
| **Chemist** | Perform lab work — enter test results, record cultures and antibiotic sensitivities. |
| **Employee** | Basic system access for general supporting tasks. |
| **Receptionist** | Front-desk operations — patient registration, billing, invoicing, and report distribution. |
| **Patient** | View personal medical reports, invoices, and billing history securely online. |

## Key Features

- **Role-Based Access Control:** Distinct dashboards and permissions for Admins, Chemists, Employees, Receptionists, and Patients.
- **Medical Report Management:** Complete lifecycle management of patient tests, cultures, and antibiotic sensitivities including sample entry by Chemists.
- **AI-Powered OCR Scanning:** Allows receptionists to scan physical medical reports and automatically populate structured data into the system using advanced AI and LLMs.
- **Automated WhatsApp Delivery:** Securely generate and send PDF medical reports to patients directly via WhatsApp.
- **Billing System:** Integrated invoicing, contract pricing, and package management.
- **Multi-tenant Isolation:** Ensures that data (like patients and phone numbers) is securely scoped per laboratory.
